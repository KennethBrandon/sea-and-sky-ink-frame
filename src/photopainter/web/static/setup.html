Connect the frame to Wi-Fi

Pick your home network. The frame hears 2.4 GHz Wi-Fi only, so a network on 5 GHz alone won't be here.

    Now look at the frame

    It's trying . Your phone will drop off the frame's network while it does.

    In about a minute the frame's screen says whether it worked. If it asks you to try again, your phone should rejoin by itself, and this page will still be here.

    The setup network has ended

    To start it again, hold the back button on the frame for a second, then let go.
